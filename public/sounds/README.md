# Button samples

Switch A (`switch-1.mp3`) plays on the main deck's `.abtn` buttons.
Switch D (`switch-4.mp3`) plays on the other player buttons.

Original, unmodified samples from Corey Epstein's [Soft Sounds](https://coreyepstein.com/softsounds):

- https://coreyepstein.com/softsounds/foley/switch-1.mp3
- https://coreyepstein.com/softsounds/foley/switch-4.mp3
